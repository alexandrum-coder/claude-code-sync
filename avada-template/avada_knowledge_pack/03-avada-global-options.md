# 03 - Avada Global Options

Global Options trebuie folosite pentru stiluri comune pe tot website-ul. Claude trebuie sa recomande Global Options inainte de CSS custom.

## Zone tipice de configurat

### Layout general
- Site width
- Content width
- Boxed vs wide layout
- Container padding global
- Page title bar settings

### Culori globale
- Primary color
- Secondary color
- Accent color
- Background colors
- Text color
- Heading color
- Link color / hover color

### Tipografie
- Body font
- Heading font
- H1-H6 sizes
- Line height
- Letter spacing
- Responsive typography daca este disponibil

### Buttons
- Stil buton principal
- Stil buton secundar
- Border radius
- Padding
- Font size
- Hover state

### Forms
- Input style
- Label style
- Button style
- Error/success messages

### Header / Footer
- Logo
- Menu typography
- Menu colors
- Sticky behavior daca este cerut
- Mobile menu behavior
- Footer columns / copyright

### Responsive
- Breakpoints pentru Medium / Small screens
- Responsive typography
- Visibility rules
- Container/Column responsive settings

### Performance
- Dezactiveaza features nefolosite daca Avada permite.
- Evita sliders grele si efecte excesive.
- Foloseste imagini optimizate.
- Evita custom scripts inutile.

## Reguli pentru Claude
- Cand propui culori sau fonturi recurente, mentioneaza ca trebuie setate in Global Options.
- Cand propui butoane recurente, mentioneaza Button Global Styling.
- Cand propui spacing general, incearca intai Global Options + Container/Column settings.
- Nu scrie CSS global pentru lucruri pe care Avada le controleaza nativ.
