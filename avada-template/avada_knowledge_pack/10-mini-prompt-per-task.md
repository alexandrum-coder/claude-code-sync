# 10 - Mini prompts pentru taskuri punctuale

## Prompt pentru o pagina noua
Using the attached Avada Knowledge Pack, design this page using only native Avada Builder elements where possible. For every section, specify Container, Columns, Avada Elements, content, CTA, responsive behavior and whether it should be saved as a Library/Global Element. Avoid custom code unless impossible natively.

## Prompt pentru refacerea unei pagini existente
Audit this page and convert the design into an Avada-native implementation plan. Replace custom HTML/CSS/JS suggestions with Avada Containers, Columns, Elements, Global Options, Layouts and Library components wherever possible. Output a section-by-section rebuild checklist.

## Prompt pentru landing page lead generation
Create a conversion-focused landing page in Avada. Use native Avada elements only where possible: Container, Columns, Title, Text Block, Button, Icon Box, Checklist, Testimonials, Toggles/FAQ and Avada Form. Include copy, CTA, form fields, responsive behavior, SEO notes and implementation checklist.

## Prompt pentru header/footer
Create an Avada-native Header and Footer strategy using Avada Layouts/Layout Sections. Specify elements, menu behavior, logo placement, CTA, mobile menu behavior, footer columns, social links and reusable/global components.

## Prompt pentru e-commerce
Using Avada WooCommerce Builder and native Woo elements, design the WooCommerce templates: Shop, Product Archive, Single Product, Cart and Checkout. Avoid WooCommerce template overrides unless Avada cannot solve the requirement.

## Prompt pentru audit custom code
Review this implementation proposal and identify every place where custom code can be replaced by native Avada features. Return a table with: custom proposal, native Avada alternative, element/settings to use, and whether custom code is still justified.
