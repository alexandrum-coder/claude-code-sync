# Avada Knowledge Pack pentru Claude

Scop: acest pachet ii ofera lui Claude un cadru compact pentru a proiecta si implementa website-uri WordPress folosind tema Avada, Avada Builder si elementele native ale temei, fara sa incarce documentatia completa in context.

Cum se foloseste:
1. Incarca in Claude fisierele 00, 01, 02, 03, 04 si 08 pentru orice proiect Avada.
2. Incarca 05 doar daca website-ul are formulare / lead generation.
3. Incarca 06 doar daca proiectul include magazin online WooCommerce.
4. Incarca 07 doar daca ai nevoie de custom development, hooks, child theme sau modificari PHP/CSS/JS.
5. Incarca 09 ca prompt principal in Claude.

Regula principala: Claude trebuie sa propuna intai solutii native Avada. Custom HTML/CSS/JS/PHP se foloseste doar daca nu exista o solutie nativa in Avada.
