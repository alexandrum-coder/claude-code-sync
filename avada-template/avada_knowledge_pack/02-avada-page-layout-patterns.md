# 02 - Avada Page Layout Patterns

Acest fisier contine structuri de pagina pe care Claude trebuie sa le propuna folosind elemente native Avada.

## Landing Page B2B / servicii

### Sectiuni recomandate
1. Hero
2. Trust bar / logo-uri clienti
3. Problemele clientului
4. Solutia oferita
5. Servicii / capabilities
6. Proces de lucru
7. Studii de caz / rezultate
8. Testimoniale
9. FAQ
10. CTA final / formular

### Implementare Avada
Hero:
- Container full-width sau boxed
- 2 Columns: text + imagine/visual
- Title H1
- Text Block
- Button principal + Button secundar
- Checklist scurt sau Icon Boxes

Servicii:
- Container
- Title H2
- Text Block introductiv
- 3 sau 4 Columns
- Icon Box pentru fiecare serviciu

Proces:
- Container
- Columns 3-5 pasi
- Icon Box / Counter / Title + Text Block

FAQ:
- Container
- Title H2
- Toggles

CTA final:
- Container cu background diferit
- Title
- Text Block
- Button sau Avada Form

## Website corporate

### Pagini recomandate
- Home
- About
- Services
- Service Detail template
- Case Studies
- Blog / Resources
- Contact

### Elemente recurente
- Header global: Layout Section Header
- Footer global: Layout Section Footer
- CTA global: Library Global Element
- Service cards: Library element reutilizabil
- Testimonial block: Library element

## Website local business

### Sectiuni Home
1. Hero cu oferta clara
2. Servicii principale
3. De ce noi
4. Galerie / rezultate
5. Reviews
6. Zona deservita / locatie
7. Contact rapid

### Elemente Avada
- Hero: Container + Title + Text Block + Button + Image
- Servicii: Icon Box / Image + Title + Text
- Reviews: Testimonials
- Galerie: Gallery
- Locatie: Map
- Contact: Avada Form

## Website portofoliu / fotografie

### Sectiuni Home
1. Hero vizual
2. Categorii servicii
3. Galerie selectata
4. Poveste / stil
5. Pachete
6. Testimoniale
7. CTA booking

### Elemente Avada
- Hero: Container cu background image/video, Title, Button
- Categorii: Columns + Image + Title + Text
- Galerie: Gallery / Slider
- Pachete: Pricing Table daca este disponibil sau Columns + Title + Checklist + Button
- Booking: Avada Form / Button catre calendar

## Website SaaS / software

### Sectiuni Home
1. Hero cu promisiune clara
2. Pain points
3. Product/features
4. Use cases
5. Integrations
6. Security / trust
7. Pricing / request demo
8. FAQ
9. CTA final

### Elemente Avada
- Features: Icon Box
- Use cases: Tabs sau Cards cu Columns
- Integrations: Image/logo grid
- Pricing: Pricing Table daca este disponibil; altfel Columns + Checklist + Button
- FAQ: Toggles
- Lead: Avada Form

## Reguli pentru toate paginile
- Fiecare pagina trebuie sa aiba un singur H1.
- Foloseste H2 pentru sectiuni principale.
- Pastreaza CTA vizibil in hero si la final.
- Salveaza sectiunile recurente ca Library / Global Elements.
- Nu folosi prea multe animatii.
- Optimizeaza pentru mobile: ordinea coloanelor, spacing, dimensiunea titlurilor, imaginile.
